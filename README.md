
# 📌 Project Timeline Tracker

A web-based application designed to help users plan, manage, and track projects and tasks with timelines and deadlines in an organized way.

---

## 🎯 Project Objective

The main objective of this project is to provide a centralized platform where users can:

- Create projects  
- Add and manage tasks  
- Track progress and deadlines  
- Monitor project timelines efficiently  

This system reduces manual tracking and improves productivity.

## 🔄 Project Flow

1. User registers and logs in  
2. User accesses dashboard  
3. User creates a project  
4. User adds tasks to the project  
5. User tracks task progress  
6. System stores and updates data in database

## 🚀 Getting Started

### Prerequisites

- Node.js  
- pnpm  
- MySQL (optional for production)

---

### Installation Steps

1. Clone the repository  
git clone <repository-url>

2. Navigate to project folder  
cd project-tracker-ui

3. Install dependencies  
pnpm install

4. Generate Prisma Client  
npx prisma generate

5. Apply database migrations  
npx prisma migrate dev

6. Start the application  
pnpm dev

7. Open browser  
http://localhost:3000
